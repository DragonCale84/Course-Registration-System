# Course Registration System

This is a collaborated group effort in coming up with our own ways in creating a course registration system that students could enroll in. The core features of this course registration system is to allow students (or users) to add and drop courses, edit their current course, add or edit their student information, and drag and drop their courses to enroll in the course subject. Available free-space and taken seats are also displayed in ensuring that students are aware of the available number before enrolling into their course.

One of the special features that allows our system to stand out is that students are allowed to submit a form review to add a new course under the improvement and recommendations and if validated with enough evidence and proof that it's viable, lecturers can be assigned and a new course can be suggested for creation under the school or university.
